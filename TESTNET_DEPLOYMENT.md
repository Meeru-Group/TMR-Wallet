# Thanvi Testnet Deployment

## Required environment

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST/DATABASE?sslmode=require
NODE_ENV=production
TMR_NETWORK=testnet
TMR_BLOCK_TIME_MS=12000
TMR_FAUCET_AMOUNT=1000
TMR_REQUEST_BLOCK_PRODUCTION=true
```

Optional:

```env
TMR_BLOCK_PRODUCER_KEY=replace-with-a-secret
```

If a custom faucet address is used, it must be a canonical `TMR1` address generated by the wallet address scheme.

## Existing database cleanup

If the deployed Explorer already shows demo blocks/transactions, set:

```env
TMR_RESET_TESTNET_CHAIN=true
```

for one deployment only. Remove it after the migration succeeds.

## Expected clean state

Immediately after reset and before any user transaction:

- Latest block: `0`
- Blocks (including genesis): `1`
- Transactions: `0`
- Pending transactions: `0`
- Validators: `3`
- Total testnet supply: `10,000,000,000 TMR`

A refresh must not increase the block height.

After a real faucet/send transaction is submitted, the pending transaction can be finalized by the block producer. The Explorer then reads the resulting block from PostgreSQL.
